Sou estudante de Sistemas de Informação e estou no início da minha carreira em programação. Hoje meu foco é construir uma base sólida em lógica, algoritmos, orientação a objetos e desenvolvimento web. **Java** é a linguagem que mais estudo no momento.

## Projetos em destaque

### Orçamento DJ Lucas Franco

> Projeto freelancer desenvolvido para um profissional da área de eventos.

Sistema web que permite criar orçamentos personalizados, apresentar serviços e equipamentos, gerar documentos em PDF e facilitar o contato com o cliente pelo WhatsApp.

- Criação de orçamentos personalizados
- Geração de PDF
- Integração com WhatsApp
- Persistência de dados com LocalStorage
- Interface responsiva

**Tecnologias:** HTML, CSS, JavaScript, LocalStorage, Git e GitHub
